# 奈奈参考实现（案例，不是标准答案）

> 只展示“怎么在真实环境里落地”，不是让其他 AI 照抄路径。

## 规模

```text
图书馆：约 180 张卡
事实库：数万条
表情包：800+
日志：30+ 天
群：7 个
```

## 结构

```text
workspace/library/
  人物/
  事件/
  规则/
  项目/
  知识/
  群/
  语感/
  成长/
  工具/
  index.md
```

## 检索

```text
关键词/标题/摘要匹配
按来源/状态/精度加权
top 1–3
封存/隔离不参与
```

## 上下文

```text
轻首屏：身份 + 当前 + 最近几句
按需：1–3 张卡
群聊：旁听只入档，被叫才进
```

## 世界树

```text
imma-index.json
  anchor / precision / status / provenance
只在检索时用
不改卡正文
```

## 教训

```text
1. 索引卡不能当答案
2. 没有来源的卡要隔离
3. “你以前说过”要剥掉再查
4. 封存/隔离要盖过“想起来了”
5. 一个总入口，比三套记忆更可靠
```
